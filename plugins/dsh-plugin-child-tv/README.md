# 儿童定时播放

> 儿童定时播放・家长远程控制：mpv 定时全屏播放本地/网络音视频，家长可远程播放、停止、锁定电脑，儿童观看页无操作按钮

## 基本信息

| 字段 | 值 |
| --- | --- |
| 插件 Key | `dsh-plugin-child-tv` |
| 版本 | 1.0.0 |
| 分类 | education |
| 入口页面 | `/child-tv-admin` |
| 类型 | 平台内置集成插件 |

## 说明

本插件为 Life-OS 平台内置集成插件，页面与后端逻辑随主工程一起开发维护，
由「插件中心」统一管理启用 / 暂停 / 卸载。

## 页面入口

访问 `/child-tv-admin` 进入插件主页面。

## 数据存储

插件数据保存在本地 `user-data/plugins-data/dsh-plugin-child-tv/` 目录，
遵循「本地文件存储优先，后期可切换线上数据库」的项目规则。

## 使用方式

- 在插件中心启用后，侧边栏导航将自动出现对应菜单；
- 插件暴露的 AI 方法可在 AI 聊天框中使用自然语言调用（在插件中心详情页可查看方法列表）。
