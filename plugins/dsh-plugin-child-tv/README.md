# 儿童定时播放

> 儿童定时播放・家长远程控制：mpv 定时全屏置顶播放本地/网络音视频，家长可远程播放、停止、管理时段；儿童观看页无操作按钮

## 基本信息

| 字段 | 值 |
| --- | --- |
| 插件 Key | `dsh-plugin-child-tv` |
| 版本 | 1.2.0 |
| 分类 | education |
| 入口页面 | `/child-tv-admin` |
| 类型 | 平台内置集成插件 |

## 说明

本插件为 Life-OS 平台内置集成插件，页面与后端逻辑随主工程一起开发维护，
由「插件中心」统一管理启用 / 暂停 / 卸载。

**单机模式**：服务运行所在的电脑就是被控制的电脑（本机调度 + 本机 mpv 播放）。
家长可通过 `http://<本机IP>:5180/child-tv-admin` 在第二台电脑的浏览器上登录控制台，
远程修改时段、开启/关闭时段、修改内容来源（文件夹/单文件/URL）。
不依赖儿童账号绑定、绑定码或远程受控服务。

## 页面入口

- 家长控制台：`/child-tv-admin`（登录后管理时段、立即播放/停止、日志统计、设置）
- 儿童观看页：`/child-tv`（只读展示当前播放与下一时段，无操作按钮，可设 PIN）

## 数据存储

插件数据保存在插件自身目录下 `user-data/plugins/dsh-plugin-child-tv/data/`，控制台提供「打开所在文件夹」（快捷键 Ctrl+Shift+O）快捷定位。
遵循「本地文件存储优先，后期可切换线上数据库」的项目规则。

## 使用方式

- 在插件中心启用后，侧边栏导航将自动出现对应菜单；
- 时段内容来源支持三种：**合集（文件夹）** 自动扫描全部音视频按文件名排序循环播放、**单文件** 只播放选中的一集、**URL 链接** 网络直链在线播放；
- 播放时以 mpv **全屏 + 屏幕最上层（置顶）** 播放，结束自动退出；
- 插件暴露的 AI 方法可在 AI 聊天框中使用自然语言调用（在插件中心详情页可查看方法列表）。
